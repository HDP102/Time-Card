This adds an extra-scope rule to the A: Active Directory | E: Production ruleset permitting the OneTrust worker nodes, labelled R: Web and A: Data Privacy and Compliance Tool, to reach ten domain controllers on TCP 1433 from 10.192.50.0/26, to support data inventory scanning for identification and compliance purposes. Before implementation, please confirm the port and destination set, as TCP 1433 is SQL Server while the destinations are labelled R: Domain Controller, including the PDC. If OneTrust is intended to scan SQL instances, those instances should be the destinations rather than the domain controllers, and if the targets are genuinely the domain controllers then the required ports would be AD-related rather than 1433. Please also populate the Service column in the Firewall Access Change Details table so the approved port is recorded on the request itself rather than only in the description, and confirm that scanning access to the primary domain controller is approved by the Active Directory team.

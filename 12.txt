Hey Hardik,
 
To answer your questions:
 
Log categories -  send the newer categories only, you don't need to enable legacy azure diagnostics.
Which server reads it: - Data Collector only, the one pointing to the Azure Subscriptions.
Authentication - Firemon needs the storage account keys and it must stay enabled. Entra ID is not supported for now.
One storage account - That's correct, you can use one storage account for both Firewalls and you should use the "Alternate subscription ID" for this.

FireMon settings: - The only important thing for FireMon is the name if you want to enter the specific name in "Storage Accounts", else, as the tooltip says, leave it blank and it will scan all storage accounts in the subscription.
Where to enable it: Log Monitoring - Enable it both on the management station as well as the child devices.
Retention - Once FireMon reads the data, it's pulled to the Security manager and populates the hit counts, 1-3 days should be enough for Firemon to pull this data. If you have any issues with servers communicating or crashing, that may not be enough time if you don't catch the problem on time.
 
NSGs - Yes, FireMon can read both on the same storage account.
 
Device packs: you cannot delete device packs, you should just upload the newer ones and they will be overwritten with the new ones.

This adds an extra-scope rule to the A: Tableau - v10.4.3 (PCE_Local) | E: Test ruleset permitting 168.63.129.16 to reach the two Tableau Server TEST Azure VMs on TCP 443, so that Azure load balancer health probes can reach the backend pool. One note for consistency: the source object is labelled E: Production while the ruleset and destination workloads are E: Test. This has no practical effect here, since the address is an Azure platform endpoint rather than a workload, but please confirm the Azure Wire Server object is labelled consistently so that Production-scoped objects are not referenced from Test rulesets in future changes.

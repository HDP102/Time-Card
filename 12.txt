No, it’s not a TLS server cert. It’s a client-authentication cert our script uses to sign its token request to Entra ID (OAuth client credentials with a certificate). Nothing terminates TLS with it, and there’s no F5 VIP or DNS record behind it.

The CN/DNS name follows the Azure SSO team’s required format for Entra ID OAuth clients: {App ID}-{Application Name}.EntraID.AuthN.pge.com (per the “PG&E Entra ID Client Credential OAuth Flow” wiki, Abhishek Chauhan’s page). Prod requires it to be signed by the internal PG&E CA.

I picked the PGE Server template.

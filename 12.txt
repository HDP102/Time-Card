Hey Walker, FireMon got back to me with the details. They only need the newer firewall log categories (Network Rule, Application Rule, NAT Rule), not the legacy ones. The FireMon data collector V50SECAPL008 is what reads the storage account. One thing to note: FireMon authenticates with the storage account keys, so shared key access needs to stay enabled, since they don’t support Entra ID yet. One storage account for both firewalls is fine on their side. Retention only needs to be a few days since FireMon pulls the data in, so something like 7 days should give us plenty of buffer.

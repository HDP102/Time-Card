## Part 2: Add 5 rules to the FireMon ruleset

1. Go to **Segmentation > All Policies**.
2. Open **ICS_Firewall Policy Manager | Production**.
3. Add each rule below the same way you added rules 1 to 3.
4. For every rule:
   - **Rule type:** Intra-Scope
   - **Source:** `ICS_Firewall Policy Manager` (the ICS label, not A: Firemon)
   - **Destination:** pick the IP list from the dropdown. Don't type free text.
   - **Service:** add it as port/protocol, the same way you did 443 TCP on rules 1 to 3.
5. Save each rule. **Do not provision.**

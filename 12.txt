Policy Change Type: Proxy (already set)

What needs to be changed in proxy policy?

Please add the following URL to an allow list in ZIA URL filtering:

www.screencast.com/users/firemonsupport/*

This path is currently blocked under the FileHost category by rule D23. The entry should be placed in a custom allow category referenced by a URL filtering rule ordered above the FileHost block rule, and scoped to the Network Security Engineering team rather than all users. Scoping to the firemonsupport path rather than the screencast.com domain limits the exception to FireMon published content and does not grant access to the upload or file sharing functions of the platform.

Business Justification

FireMon hosts its product documentation videos on Screencast under the firemonsupport account, and those videos are embedded directly within the FireMon Support Center articles. The Network Security Engineering team uses this documentation for device onboarding, health checks, licensing, and the FMOS upgrade currently in progress, and the embedded videos fail to load without this access. Access is view only, as the team is consuming vendor published content rather than uploading or sharing files, and the firemonsupport path is read only to anyone outside that account. Permanent access is requested rather than a 24 hour exception because FireMon support documentation is referenced continuously as part of ongoing platform administration and the FireMon estate remediation work, and a temporary window would require repeated requests for routine vendor documentation.

The FireMon data collector (V50SECAPL008, 10.192.24.52) is being blocked from reaching Zscaler's API endpoint, zsapi.zscalertwo.net (167.103.95.63), on TCP 443.

The SD-WAN classifies that destination as Zscaler and keeps it out of the Zscaler tunnel, so it goes out the direct internet path on v50pubrtr001. There it hits the CorporateLAN → Default "Match Everything → Deny" rule at priority 9900 and is dropped. The fix is a narrow allow for that source, destination and port above rule 9900.

This permits TCP 1422 from workloads labelled L: Azure, A: Imaging, E: QA, R: Adlib to workloads labelled L: Aurora, A: Mainframe (PCE_Local), E: Production, R: Server, to allow the imaging application to access IBM MQ. Unlike the companion requests in this series, which remain within non-production, this rule allows a QA-labelled workload to initiate connections into the production mainframe environment, so please confirm this crossing is approved by the mainframe and application owners and record that approval on the request. Please also scope the destination to the specific queue manager host rather than the current label set, which matches every production server labelled A: Mainframe. Finally, please confirm whether TLS is configured on the MQ channel, as IBM MQ channels transmit in cleartext by default and TCP 1422 is a non-default listener port.

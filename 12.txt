This permits TCP 1445 from workloads labelled L: Azure, A: SpringApps_DSS (PCE_Local), E: Development, R: DSS to workloads labelled L: Azure, A: Imaging, E: QA, R: CMOD, so imaging applications can search and retrieve documents from the CMOD repository. The destination label set includes both application and role, which keeps the rule scoped to the intended CMOD workloads rather than to QA workloads generally. Two items to confirm before implementation. Please verify whether the CMOD library server connection on TCP 1445 is configured for SSL, as that port is cleartext by default and this carries document retrieval traffic. Please also confirm the environment crossing is intended, as the source is labelled E: Development while the destination and associated application are QA.
